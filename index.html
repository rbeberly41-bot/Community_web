01 · PROPÓSITO

Una comunidad más conectada

Community Care Network nace como una propuesta para mejorar la comunicación y el seguimiento de las necesidades que se presentan dentro de una comunidad.

!

Problema identificado

La falta de un sistema centralizado puede provocar retrasos, pérdida de información y dificultades para dar seguimiento a los problemas reportados por los vecinos.

◎

¿Por qué se desarrolló?

Para centralizar el registro, administración y seguimiento de reportes comunitarios mediante un sistema informático organizado y fácil de utilizar.

♧

¿A quién beneficia?

A los ciudadanos y a las personas encargadas de consultar, organizar y dar seguimiento a las necesidades reportadas dentro de la comunidad.

✓

Finalidad

Fortalecer la participación ciudadana y facilitar la colaboración entre la comunidad y las personas o instituciones que atienden sus necesidades.

02 · OBJETIVOS

Lo que busca lograr el proyecto

01
OBJETIVO GENERAL

Fortalecer la gestión de necesidades comunitarias

Desarrollar un sistema informático que permita registrar, consultar y dar seguimiento a reportes de problemas comunitarios, favoreciendo una comunicación más organizada entre los ciudadanos y quienes participan en la atención de estas necesidades.

02

Registrar

Registrar reportes comunitarios con la información necesaria para facilitar su consulta y seguimiento.

03

Centralizar

Centralizar la información de los reportes para reducir la pérdida de datos y facilitar su administración.

04

Dar seguimiento

Facilitar el seguimiento de los reportes mediante estados como Pendiente, En proceso y Resuelto.

03 · ALCANCE

Hasta dónde llega el sistema

El proyecto establece una frontera clara entre las funciones contempladas y las características que quedan fuera de esta versión.

✓ Incluye

  • Registro de usuarios.
  • Inicio de sesión.
  • Creación y almacenamiento de reportes.
  • Consulta de reportes.
  • Seguimiento mediante estados.
  • Registro de información de ubicación.
  • Consulta de jornadas de limpieza comunitaria.
  • Almacenamiento de información en base de datos.

× No incluye

  • Aplicación móvil para Android o iOS.
  • Integración con sistemas gubernamentales o privados.
  • Geolocalización, GPS o navegación en tiempo real.
  • Chat, videollamadas o llamadas de emergencia.

04 · CARACTERÍSTICAS

Funciones principales

El sistema reúne funciones orientadas al registro, consulta y seguimiento de las necesidades comunitarias.

01

Registro de usuarios

Permite crear una cuenta con los datos necesarios para utilizar el sistema.

02

Inicio de sesión

Permite acceder al sistema utilizando las credenciales registradas.

03

Crear reportes

Permite registrar el tipo de problema, descripción y ubicación del reporte.

04

Mis reportes

Permite consultar los reportes realizados y visualizar su información y estado.

05

Gestión de estados

Los reportes pueden encontrarse como Pendiente, En proceso o Resuelto.

06

Jornadas de limpieza

Incluye un calendario para consultar y registrar jornadas de limpieza comunitaria.

07

Base de datos

La información del sistema se almacena y consulta mediante una base de datos MySQL.

08

Validación y seguridad

Se contemplan validaciones de información, autenticación y protección de los datos.
